{{- /* Versions in use, ranked by recent volume, never lifetime (§3.5-3, §8a-11). Call: $v := partialCached "data/versions.html" (dict "repo" "python-sdk" ["asof" "YYYY-MM-DD"] ["top" 8]) "versions" "python-sdk" asof: the page's "Data as of" date (default the newest snapshot date); top: rows before "Other" (default 8).
