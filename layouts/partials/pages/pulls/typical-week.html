{{- /* "Typical week" of merged PRs (design system v4 3.7): the median of the weekly snapshots pulls.merged_7d over the prior 12 complete ISO weeks, skipping weeks without data. One sample per week (its last reading); the current, unfinished week is not a sample. Shared by the Pull requests "Review speed" strip and the Repositories table, which show it only with 4 or more samples. Input: a repos.json entry (or any data/repo.html reference). Returns dict {value float|nil, n int, from, to (sampled week starts), title (names the samples through the formatters, "" when there are none)}. Never emits. */ -}} {{- $s := partial "data/series.html" (dict "repo" . "path" "pulls.merged_7d") -}} {{- $w := partial "data/week-bins.html" (dict "points" $s.points "agg" "last" "weeks" 12 "partial" false) -}} {{- $vals := slice }}{{ $from := "" }}{{ $to := "" -}} {{- range $w.points | default slice -}} {{- if ne .value nil -}} {{- $vals = $vals | append (float .value) -}} {{- if eq $from "" }}{{ $from = .date }}{{ end }}{{ $to = .date -}} {{- end -}} {{- end -}} {{- $med := 0.0 }}{{ $n := len $vals -}} {{- if gt $n 0 -}} {{- $sorted := sort $vals -}} {{- $mid := div $n 2 -}} {{- if eq (mod $n 2) 1 }}{{ $med = index $sorted $mid -}} {{- else }}{{ $med = div (add (index $sorted (sub $mid 1)) (index $sorted $mid)) 2.0 }}{{ end -}} {{- end -}} {{- $title := "" -}} {{- if gt $n 0 -}} {{- $end := ((time.AsTime $to).AddDate 0 0 6).Format "2006-01-02" -}} {{- $title = printf "Median PRs merged, %s sampled, %s" (partial "fmt/count.html" (dict "v" $n "noun" "week")).text (partial "fmt/range.html" (dict "from" $from "to" $end)).text -}} {{- end -}} {{- return dict "value" (cond (gt $n 0) $med nil) "n" $n "from" $from "to" $to "title" $title -}}
