{{- /* One row of the classified PR queue (design system v4 4.16). Ctx: dict {r, off, k}. r a row from pages/pulls/rows.html. A row with r.parent is another PR of a duplicate cluster: an ordinary row that carries the attribute tag "Duplicate of #N" (N is the primary PR of the cluster). off true when the row is outside the default view (data-off: hidden at first paint). k the index of the row inside the default view, for the first-paint marks (data-over past 25, data-over-phone past 10). Cells in the fixed order: PR (ui/row-item.html: id, author and role, lines changed, "Touches auth", "Duplicate of #N"), Status (ui/status-cell.html: the badge and, under it, the detail phrase of pages/pulls/reason.html), Overdue (ui/sla.html), Age (whole days; the title names the opening date). There is no Detail column. The data has no labels for classified PRs. One duration rule: every day count is floored, and a detail day count is never larger than the Age of the row. */ -}} {{- $r := .r }}{{ $pr := $r.pr }}{{ $k := int (.k | default 0) -}} {{- $num := int ($pr.number | default 0) -}} {{- $attrs := slice -}} {{- if eq $pr.is_auth true }}{{ $attrs = $attrs | append "Touches auth" }}{{ end -}} {{- with $r.parent }}{{ $attrs = $attrs | append (printf "Duplicate of #%d" (int .)) }}{{ end -}} {{- $d := dict }}{{ if not $r.parent }}{{ $d = partial "pages/pulls/reason.html" $pr }}{{ end -}} {{- if ne $d.days nil }}{{ $d = merge $d (dict "days" (math.Min (math.Floor (float $d.days)) (math.Floor (float $r.age)))) }}{{ end }} {{ partial "ui/row-item.html" (dict "title" (string ($pr.title | default "")) "href" $pr.url "id" (printf "#%d" $num) "author" $pr.author "role" $r.role "diff" (dict "add" $pr.additions "del" $pr.deletions) "attrs" $attrs) }} {{ partial "ui/status-cell.html" (dict "status" $r.st "detail" $d) }} {{ partial "ui/sla.html" (dict "rules" $r.rules) }} {{ partial "ui/value.html" (dict "kind" "dur" "d" $r.age "unit" "d" "compact" true "opened" $r.opened) }}
