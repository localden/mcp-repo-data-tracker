{{- /* Org-wide change of one snapshot metric against a dated earlier snapshot (design system v4 4.5: a "waiting, over 7 days" tile has a delta with the base "vs {date}" when a snapshot about 30 days older exists, otherwise no delta and no base). Returns a dict, never emits. Call: $d := partial "pages/overview/org-delta.html" "issues.without_response_7d" Per repository, data/series.html finds the snapshot about 30 days back (cmp30). Both sums cover only the repositories that have the current and the earlier reading, so like is compared with like; the tile says how many that is in its coverage note. Returns {cur, prev: float|nil (nil when no comparison exists), date ("YYYY-MM-DD", the oldest comparison date), k (repositories compared), n (repositories with a current reading)}. */ -}} {{- $path := . -}} {{- $cur := 0.0 }}{{ $prev := 0.0 }}{{ $k := 0 }}{{ $n := 0 }}{{ $date := "" -}} {{- range site.Data.repos.repositories -}} {{- $s := partial "data/series.html" (dict "repo" . "path" $path "days" 35) -}} {{- if ne $s.cur nil -}} {{- $n = add $n 1 -}} {{- with $s.cmp30 -}} {{- $cur = add $cur (float $s.cur) }}{{ $prev = add $prev (float .value) }}{{ $k = add $k 1 -}} {{- if or (eq $date "") (lt .date $date) }}{{ $date = .date }}{{ end -}} {{- end -}} {{- end -}} {{- end -}} {{- $out := dict "cur" nil "prev" nil "date" "" "k" 0 "n" $n -}} {{- if gt $k 0 }}{{ $out = dict "cur" $cur "prev" $prev "date" $date "k" $k "n" $n }}{{ end -}} {{- return $out -}}
