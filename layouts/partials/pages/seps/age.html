{{- /* Hours from a seps.json moment to seps.json lastUpdated, for every duration on the SEPs page (Age, Last activity). Returns a float, or -1.0 when unknown. Never emits; ui/value.html (kind "dur", unit "d") prints the result. Dict {days, at, ref}: days = the pipeline's whole-day count (daysWaiting, daysInCurrentStatus, lastActivityDays); at = the matching timestamp (createdAt, updatedAt, lastActivityAt); ref = Unix seconds of seps.json lastUpdated. Whole days win, so a cell matches the pipeline's own count (319 days for daysWaiting 319). Below 2 days the timestamp is used, so a SEP opened this morning reads as less than a day. */ -}} {{- $h := -1.0 -}} {{- $at := 0 }}{{ with .at }}{{ $at = (time.AsTime .).Unix }}{{ end -}} {{- $exact := -1.0 -}} {{- if and (gt $at 0) .ref }}{{ $exact = math.Max 0.0 (div (float (sub .ref $at)) 3600.0) }}{{ end -}} {{- if ne .days nil -}} {{- $h = math.Max 0.0 (mul (float .days) 24.0) -}} {{- if and (lt $h 48.0) (ge $exact 0.0) }}{{ $h = $exact }}{{ end -}} {{- else if ge $exact 0.0 -}} {{- $h = $exact -}} {{- end -}} {{- return $h -}}
