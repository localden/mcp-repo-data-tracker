{{- /* Caption lines of a SEP tile (brief 3.4-1, design system v3 §4.5). Context: a slice of phrases, most important first ("oldest 319 days", "12 need WG support"). Returns a dict for ui/kpi.html: qualifier = the first phrase (caption line 1, the one a phone tile keeps), context = the rest joined with commas (caption line 2). An empty slice returns two empty strings. */ -}} {{- $q := "" }}{{ $rest := slice -}} {{- range $i, $t := (. | default slice) -}} {{- if eq $i 0 }}{{ $q = $t }}{{ else }}{{ $rest = $rest | append $t }}{{ end -}} {{- end -}} {{- return dict "qualifier" $q "context" (delimit $rest ", ") -}}
