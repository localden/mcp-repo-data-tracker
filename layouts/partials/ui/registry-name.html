Returns a dict (empty for nil input): {registry: "PyPI", key: "pypi", package: "mcp", url: "https://pypi.org/project/mcp", label: "PyPI · mcp"}. Proper names per brief 6.1 rule 6: npm, PyPI, NuGet, crates.io, RubyGems.
