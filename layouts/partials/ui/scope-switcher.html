{{- /* Scope switcher (design system v3 §4.2, §4.12): a "Switch repository" .v-btn with a chevron that opens a menu of sibling URLs of the same page kind. ui/page-head.html places it at the right end of the H1 row (under the meta row on phone); the H1 names the scope.
