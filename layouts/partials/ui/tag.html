{{- /* Tag (design system v4 4.8): a GitHub label or a derived attribute. A 20px pill; never a link, no states. Two families, so a reader can tell labelling from classification: outlined what a person applied on GitHub: label, prio, and the "+N" that folds labels filled what VISR derived: role, attr, flag Call with a string, or a dict {text, kind, title}. kind: label (default) a GitHub label, verbatim (at most 8rem wide below 64rem, 16rem from 64rem; the full text in title) prio P0 to P3; P0 and P1 take the strong edge more "+2", the folded tags named in title role Maintainer, Bot (ui/row-item.html draws no tag for the default role, Contributor) attr a derived attribute ("Touches auth", "SEP draft", "Latest", "Duplicate of #1813", "SEP-1730", "Team target") flag a 12px circle-alert before the text ("Type conflict", the conflicting labels in title) Row tags only (ui/row-item.html): extra: true marks a label past the second (data-extra: shown below 64rem, where the tag line wraps); only: "wide" or "narrow" keeps a +N tag to one side of 64rem (data-fold; never an attribute whose name after "data-" starts with "on": Go templates escape those as script). A slice of either renders each tag inside one span.v-tags. Empty text renders nothing. */ -}} {{- $c := . -}} {{- if reflect.IsSlice $c -}} {{- if $c }}{{ range $c }}{{ partial "ui/tag.html" . }}{{ end }}{{ end -}} {{- else -}} {{- if not (reflect.IsMap $c) }}{{ $c = dict "text" $c }}{{ end -}} {{- $kind := $c.kind | default "label" -}} {{- if not (in (slice "label" "role" "prio" "flag" "attr" "more") $kind) }}{{ $kind = "label" }}{{ end -}} {{- with $c.text -}} {{- $t := string . -}} {{- $strong := or (and (eq $kind "prio") (in (slice "P0" "P1") $t)) (eq $c.strong true) -}} {{- if eq $kind "flag" }}{{ partial "ui/icon.html" (dict "name" "circle-alert" "size" 12) }}{{ end -}} {{ $t }} {{- end -}} {{- end -}}
