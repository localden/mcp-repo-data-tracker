{{- /* Overdue cell (design system v4 4.16, ruling 28): the one red thing in a row. Emits the whole . The cell shows the rule with the most days overdue: its registry name in caption text-2, then the days in strong danger; further rules fold into a "+N" tag that names them in its title. The order is rule, +N, days ("P1 bug" +1 324d): the tag belongs to the rule name, and the days are last, so they keep the column's right edge whatever the row breaches. The cell's title is the rule's "{deadline}, {source}". With days unknown the value is the danger badge "Overdue". data-v is the days (the sort key); data-rules lists every breached rule ("p1:514,follow-up:12") so ui.js can swap in the chosen rule while the SLA rule filter is active. The row's data-facets must carry "overdue" and one "rule:{key}" token per rule. No icon; the rendering never changes shape with the data. List form below 64rem has no column header, so the word "overdue" shows between the rule and the days ("First review overdue 269d", the word order every other page uses); it is hidden from 64rem and beside the badge, which already says it.
