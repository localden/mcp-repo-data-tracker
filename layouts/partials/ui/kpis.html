{{- /* KPI strip (design system v3 §4.5): one card, 3 or 4 equal tiles in a grid, 1px dividers, every tile the same height. Dict {tiles, label, id}. tiles: slice of ui/kpi.html dicts. Columns: one per tile from 48rem, 2 below (an odd last tile spans 2). label: optional aria-label for the group. Never 1 or 2 tiles: two or fewer facts are a stat list (v3 §4.6), so with fewer than 3 tiles this renders the same facts as a ui/stats.html list inside a card (and warns at build time so the page can say so explicitly). More than 4 tiles also warns. */ -}} {{- $tiles := .tiles | default slice -}} {{- $n := len $tiles -}} {{- if gt $n 4 }}{{ warnf "VISR ui/kpis: %d tiles; a KPI strip holds 3 or 4 (design system v3 §4.5)" $n }}{{ end -}} {{- if ge $n 3 -}}
{{- range $tiles }}{{ partial "ui/kpi.html" . }}{{ end -}}
{{- else if gt $n 0 -}} {{- warnf "VISR ui/kpis: %d tiles; two or fewer facts are a stat list, rendered as ui/stats.html (design system v3 §4.5)" $n -}}
{{ range $tiles }}{{ partial "ui/kpi.html" (merge . (dict "variant" "stat")) }}{{ end }}
{{- end -}}
