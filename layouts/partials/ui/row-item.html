{{- /* Item cell (design system v4 4.16): the first content cell of every work row. Emits the whole : the title link, then one meta line of designed sub-components in a fixed order. A slot with no data is omitted and the order never changes. Dict {title, href, id, repo, author, role, diff, prio, flags, attrs, tags, kids, external, site}. title verbatim, never re-cased; one line with ellipsis from 64rem, two lines below. (A SEP title drops its "SEP-2028: " prefix in the row template, because the id is the first meta slot.) href the row link (a.v-row-link). external: default true, opens a new tab with sr-only " (opens {site})"; site default GitHub. id "#1521", "SEP-2028" (verbatim). repo the repository name: only on org lists, shown only below 64rem (from 64rem the Repository column carries it). author the handle ("app/" is stripped). role: "Maintainer", "Bot" or "Contributor" (a role tag after the handle). diff {add, del}: lines changed (PRs). prio "P0" to "P3". flags: slice of {text, title} (flag tags). attrs: slice of strings or {text, title} (attribute tags). kids {n, id}: the row expander for a duplicate cluster; id is this row's id (children carry data-child-of="{id}"). tags GitHub labels: at most two are emitted, the rest are named in the title of a "+N" tag; ui.js folds any label that does not fit the line into the +N. "kind" "role") }}{{ end -}} {{- with $c.diff }}{{ if or (ne .add nil) (ne .del nil) }}{{ partial "ui/value.html" (dict "kind" "lines" "adds" .add "dels" .del) }}{{ end }}{{ end -}} {{- if $hasTags -}} {{- with $c.prio }}{{ partial "ui/tag.html" (dict "text" .
