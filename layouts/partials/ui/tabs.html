{{- /* Tabs (design system v4 4.10). Tabs switch views and nothing else: a tab never filters, and a filter is never a tab. Dict {id, label, variant, selected, tabs, panel, open, noun}. id prefix: each tab is "{id}-tab-{key}". label aria-label of the tablist ("Views"). variant "views" (default): the first band of a list card, underline tabs with counts. A view is one of the list's disjoint piles; "All" is last. Below 64rem the band is replaced by the view button, one .v-btn that opens the same choices as a menu of radio rows; both are rendered here and CSS shows one. "seg": the segmented control, for "Chart" and "Table" in a chart card head. No counts. tabs slice of {key, label, count, panel}. count: rows in the view (it does not move while filtering); a view at 0 is aria-disabled and keeps its place. A tab count is always neutral: overdue is stated by the Overdue chip and tile, never by a red count on a view (a red 288 would claim every row is overdue). panel: the id of the tab's own panel (seg); views all control one panel, the dict's panel. open true (styleguide specimens): the menu of the view button is rendered open below 64rem. noun the plural the counts count, capitalised ("PRs", "Issues", "People"): the right-hand column label of the view menu. selected the selected key. Default for views: the first tab whose count is above zero, else the first tab. ui.js: Left, Right, Home and End move and select (roving tabindex); a view tab carries data-view; seg tabs show their own panel and dispatch "visr:tabchange". */ -}} {{- $c := . -}}{{- $id := $c.id | default "tabs" -}} {{- $tabs := $c.tabs | default slice -}} {{- $seg := eq $c.variant "seg" -}} {{- $sel := $c.selected | default "" -}} {{- if and (not $sel) $tabs -}} {{- range $tabs }}{{ if and (not $sel) (ne .count nil) }}{{ if gt (float .count) 0.0 }}{{ $sel = .key }}{{ end }}{{ end }}{{ end -}} {{- if not $sel }}{{ $sel = (index $tabs 0).key }}{{ end -}} {{- end -}} {{- if $seg -}}
{{- range $tabs -}} {{- $on := eq .key $sel -}} {{- end -}}
{{- else -}} {{- $items := slice }}{{ $curLabel := "" }}{{ $curCount := "" -}}
{{- range $tabs -}} {{- $on := eq .key $sel -}} {{- $zero := false }}{{ $n := "" -}} {{- if ne .count nil }}{{ $zero = eq (float .count) 0.0 }}{{ $n = (partial "fmt/count.html" (dict "v" .count)).text }}{{ end -}} {{- if $on }}{{ $curLabel = .label }}{{ $curCount = $n }}{{ end -}} {{- $items = $items | append (dict "text" .label "value" .key "checked" $on "count" .count "disabled" (and $zero (not $on))) -}} {{- end -}}
{{ partial "ui/menu.html" (dict "id" (printf "%s-view-menu" $id) "bare" true "label" ($c.label | default "Views") "items" $items "open" $c.open "cols" (slice "View" ($c.noun | default "Items"))) }}
{{- end -}}
