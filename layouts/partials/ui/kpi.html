{{- /* KPI tile (brief 4.6 d): four fixed slots, label / value / context / sparkline. Tiles live inside one ui/kpis.html card. Dict {label, labelTitle, value, format, valueHTML, prefix, na, overdue, qualifier, delta, context, points, spark, since, filter, for, group, id}. label: plain words, no middot. labelTitle: tooltip with the definition. value: number or nil; format "num" (default: full below 10,000, compact above), "full", "compact", "dur" (value in hours), "pct" (0-100). valueHTML: pre-rendered value instead (e.g. "≥ 5.9d"); prefix: text before the value ("≥"). nil value -> "—" + sr-only na. overdue: {title} marks an SLA tile: a value > 0 renders as status (icon + --bad-text, title names the rule), 0 renders muted. Put the words in the context line ("of 238 waiting for a first review (95%)"); never repeat them as sr-only text. context line, at most 2 lines: qualifier (line 1, e.g. "no maintainer reply after 7 days"), then delta (a ui/delta.html dict, rendered when it has both values) or else context (text or HTML, e.g. a denominator or a ui/flag.html). On phones only the second line shows when both exist. points: 12 weekly bins [{date, value|nil}] (data/week-bins.html or data/org-weekly.html .points); the tile renders ui/spark.html itself (size tile; end dot in --status-critical when an overdue tile is above 0; duration y-span for format "dur"). Below 4 bins the slot shows "Tracking since {since, else the first bin with a value}". spark: pre-rendered ui/spark.html output instead of points; without either, since ("YYYY-MM-DD") prints "Tracking since Nov 10"; else the slot collapses. filter: a data-tags token; the tile becomes button[aria-pressed][data-chip] with a funnel icon (SEPs). for: id of the [data-list] it filters; group: chip group (default "kpi", so tiles are mutually exclusive). Pressed shows "Filtering · clear". No tile ever links. */ -}} {{- $c := . -}} {{- $f := $c.format | default "num" -}} {{- $v := $c.value -}} {{- $val := "" -}} {{- if $c.valueHTML }}{{ $val = $c.valueHTML -}} {{- else if eq $v nil }}{{ $val = partial "ui/num.html" (dict "v" nil "na" ($c.na | default "not tracked")) -}} {{- else if eq $f "dur" }}{{ $val = (partial "ui/dur.html" (dict "h" $v)).html -}} {{- else if eq $f "pct" }}{{ $val = partial "ui/pct.html" $v | htmlEscape | safeHTML -}} {{- else }}{{ $val = partial "ui/num.html" (dict "v" $v "mode" (cond (eq $f "num") "tile" $f)) }}{{ end -}} {{- $state := "plain" }}{{ $rule := "" -}} {{- if and $c.overdue (ne $v nil) -}}{{- $state = cond (gt (float $v) 0.0) "bad" "zero" -}}{{- end -}} {{- if reflect.IsMap $c.overdue }}{{ $rule = $c.overdue.title | default "" }}{{ end -}} {{- $spark := $c.spark }}{{ $since := $c.since -}} {{- if and (not $spark) $c.points -}} {{- $spark = partial "ui/spark.html" (dict "points" $c.points "size" "tile" "crit" (eq $state "bad") "kind" (cond (eq $f "dur") "duration" "count")) -}} {{- $spark = trim (string $spark) " \n" | safeHTML -}} {{- if and (not $spark) (not $since) }}{{ range $c.points }}{{ if and (not $since) (ne .value nil) }}{{ $since = .date }}{{ end }}{{ end }}{{ end -}} {{- end -}} {{- $delta := "" }}{{ with $c.delta }}{{ $delta = partial "ui/delta.html" . }}{{ end -}} {{- $delta = trim (string $delta) " \n" -}} {{- if $c.filter -}} {{ else }}{{ end -}}
