Dict {label, labelShort, labelTitle, value, format, valueHTML, prefix, na, overdue, qualifier, delta, context, points, spark, since, filter, for, group, id, variant}. label: plain words. labelTitle: tooltip with the definition. labelShort: phone label (< 40rem) for a label that would wrap. value: number or nil; format "num" (default: full below 10,000, compact above), "full", "compact", "dur" (hours), "pct" (0-100). valueHTML: pre-rendered value instead; prefix: text before the value. nil value -> "—" + sr-only na when the caption explains the tile; with no caption, the na text ("Not tracked") becomes the caption. overdue: {title} marks an SLA tile: a value > 0 renders as status (danger + alert icon, title names the rule); 0 renders "0". qualifier: caption line 1 ("no maintainer reply after 7 days", "of 238 waiting for a first review"). delta: a ui/delta.html dict; the badge sits in the value row and its date/vs/suffix becomes caption line 2. An empty dict renders nothing. context: caption line 2 when there is no delta (text or HTML, e.g. a ui/note.html data-quality note). points: 12 weekly bins [{date, value|nil}]; the tile renders ui/spark.html itself (danger when overdue > 0; duration y-span for format "dur"). Below 4 bins the slot shows "Tracking since {since}" when since is passed, else it collapses. spark: pre-rendered ui/spark.html output instead of points. since: "YYYY-MM-DD" (data/series.html .first). filter: a data-tags token; the whole tile becomes button[aria-pressed][data-chip] (SEPs).
